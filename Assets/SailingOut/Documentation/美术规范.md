# Sailing Out 像素美术规范

俯视 2D，船头为 +Y。PC 16:9。基准像素单位 16px，PPU = 16。帧画布采用 16 的倍数，当前对象统一 32×32，演示帆船 32×48，水面/泡沫各 128×128。Pivot 居中，缩放为 1。

轮廓为 1～2 个实像素，左上受光，右下阴影。所有对象采用二值透明度（0 或 255），不画抗锯齿、模糊或半透明外发光。水面完全不透明，泡沫图只在实像素处不透明。

纹理设置：Sprite (2D and UI)，Single，PPU 16，Point，Compression None，Mip Maps Off，Mesh Type Full Rect。对象 Clamp，水面/泡沫 Repeat。水面笔触以环绕方式落在贴图上，跨边缘的波纹继续在另一边，演示按完整平铺周期移动背景。

浮标以红/黄/青绿色区分三种外观，各 2 帧、4fps，整体轻浮 1px；礁石三种不同轮廓，静态；海鸟三种翼展/色差，各 4 帧、8fps；补给为木箱、救生圈、物资袋，各 2 帧、4fps，以不同位置的硬像素星芒闪烁；碎片为木条、水草和落叶，静态；闪电拾取物为三种绿色轮廓，各 2 帧、4fps。

所有图像均为本项目原创像素图。AI 草图流程保留作后续迭代入口，当前交付未使用 AI 出图服务。
