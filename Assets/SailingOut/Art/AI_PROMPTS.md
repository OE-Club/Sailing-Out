# AI concept prompts

These prompts produce concept sheets only. Crop each subject, reduce it to the shared palette, clean it on the 16 px grid, and export each animation frame as a separate transparent PNG using the naming rules in `Sprites/README.md`.

## Shared direction

```text
Use case: stylized-concept
Asset type: top-down 2D game sprite concept sheet
Style/medium: crisp hand-authored pixel art, readable at small size, limited cold-ocean palette, deep navy outline
Composition/framing: isolated subject centered in each cell, consistent top-down camera, no perspective change between frames
Constraints: genuinely transparent background; hard pixel edges; no antialiasing; no shadows outside the sprite; no text; no logo; no watermark
Avoid: browser branding, copied game assets, gradients, painterly texture, soft edges, subpixel detail, isometric perspective
```

## Buoys

```text
Primary request: three original nautical buoy variants for a top-down sailing game; each variant has two subtle vertical-bobbing animation frames
Color palette: safety red, yellow, white accents, cold blue-gray shadow
```

## Reefs

```text
Primary request: three original top-down reef and rock hazards with clearly different silhouettes; one static frame per variant
Materials/textures: dark wet rock, small pale foam rim, sparse teal algae accents
```

## Seabirds

```text
Primary request: three original top-down seabird variants; four consistent wing-flap frames per variant
Color palette: off-white body, navy wing tips, one warm beak accent
```

## Supplies

```text
Primary request: three original floating supply pickups, visually distinct as collectible objects; two gentle highlight-pulse frames per variant
Subject: sealed crate, life ring bundle, canvas provision pack
Color palette: light wood or canvas, white highlight, restrained yellow-green pickup accent
```

## Floating decorations

```text
Primary request: three small harmless floating-debris decorations for a top-down ocean game; one static frame per variant
Subject: driftwood cluster, seaweed patch, scattered leaves
Constraints: silhouettes must be visibly softer and less threatening than reefs
```

## Water and foam tiles

```text
Primary request: one seamless top-down ocean-water tile plus one separate sparse foam-overlay tile
Style/medium: 16 px-grid pixel art, limited deep cyan and sea-green palette
Composition/framing: square edge-to-edge tile, opposite edges match exactly, even visual density without a central focal point
Constraints: water tile opaque; foam tile genuinely transparent except for sparse foam; no objects; no text; no watermark
```
